# Upload checklist (about two minutes a video)

Files are in `C:\Users\Tom-Blake\jbspraxis_project\demo\`. **Upload the copies in `youtube\upload\`**: they
are mixed to YouTube's loudness (−14 LUFS); the files of the same name in `demo\` are for the website
(−16 LUFS). Upload in this order: 3-minute English, 60-second English, 3-minute French, 60-second French.

| Video file | Title, description, tags | Thumbnail (1280×720) | Subtitle file | Video language |
|---|---|---|---|---|
| `youtube\upload\demo-3min-en.mp4` | `youtube\titles.md`, `descriptions.md`, `tags.md` | `youtube\thumbnail-3min.png` | `captions\demo-3min-en.vtt` | English |
| `youtube\upload\demo-60s-en.mp4` | same files | `youtube\thumbnail-60s.png` | `captions\demo-60s-en.vtt` | English |
| `youtube\upload\demo-3min-fr.mp4` | same files (the French boxes) | `youtube\thumbnail-3min.png` | `captions\demo-3min-fr.vtt` | French |
| `youtube\upload\demo-60s-fr.mp4` | same files (the French boxes) | `youtube\thumbnail-60s.png` | `captions\demo-60s-fr.vtt` | French |

For each video, in YouTube Studio:

1. **Create › Upload videos**, then choose the video file.
2. **Details:** paste the title and the description (its box in `descriptions.md`). Upload the thumbnail. If
   YouTube asks you to verify the channel first, skip the thumbnail and add it later.
3. **Audience:** “No, it’s not made for kids”.
4. **Show more:** paste the tags; Altered content: No; Video language: as in the table; Category: Science &
   Technology.
5. **Video elements** and **Checks:** Next.
6. **Visibility:** Public, then Publish.
7. **Subtitles** (left menu, once the video has processed): Add language (English or French) › Upload file ›
   With timing › choose the `.vtt` file from the table › Publish.

The 3-minute descriptions already hold the chapters. The French descriptions end with the voice credit; keep it.
